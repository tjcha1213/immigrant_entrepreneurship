## Key Findings

| Finding | Data |
|---------|------|
| Fortune 500 companies founded by immigrants/children | **46.2%** (231 of 500) |
| U.S. unicorns with immigrant founder | **55%** (319 of 582) |
| U.S. patents involving immigrants | **36%** |
| AI companies with immigrant founder | **65-66%** |
| GDP at risk from restrictions (2025-2035) | **$12.1 trillion** |
| Immigrant fiscal surplus (1994-2023) | **$14.5 trillion** |
